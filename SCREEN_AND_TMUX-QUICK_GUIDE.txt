SCREEN AND TMUX - QUICK GUIDE
==============================

Both "screen" and "tmux" are terminal multiplexers: they let you run
programs inside a session that keeps running even if you disconnect
(close your SSH connection, lose network, etc.), and let you reattach
later exactly where you left off. You can also split the terminal into
multiple windows/panes.


1. SCREEN
---------

Start a new session:
    screen
    screen -S mysession        # start a named session (recommended)

Detach from the current session (leave it running in background):
    Ctrl-a  d

List running sessions:
    screen -ls

Reattach to a session:
    screen -r                  # if only one session exists
    screen -r mysession        # reattach to a specific named session
    screen -r -d mysession     # force-detach it elsewhere and reattach here

Kill/terminate a session:
    exit                       # type inside the session, closes it
    screen -X -S mysession quit    # kill from outside without attaching

Useful keyboard shortcuts (all start with Ctrl-a):
    Ctrl-a c        create a new window
    Ctrl-a n        next window
    Ctrl-a p        previous window
    Ctrl-a "        list windows and select one
    Ctrl-a A        rename current window
    Ctrl-a S        split screen horizontally
    Ctrl-a |        split screen vertically
    Ctrl-a Tab      switch between split panes
    Ctrl-a d        detach


2. TMUX
--------

Start a new session:
    tmux
    tmux new -s mysession      # start a named session (recommended)

Detach from the current session:
    Ctrl-b  d

List running sessions:
    tmux ls

Reattach to a session:
    tmux attach                    # attaches to the last session
    tmux attach -t mysession       # attach to a specific named session

Kill/terminate a session:
    exit                           # type inside the session, closes it
    tmux kill-session -t mysession # kill from outside without attaching

Useful keyboard shortcuts (all start with Ctrl-b, the "prefix" key):
    Ctrl-b c        create a new window
    Ctrl-b n        next window
    Ctrl-b p        previous window
    Ctrl-b w        list windows and select one
    Ctrl-b ,        rename current window
    Ctrl-b %        split pane vertically (side by side)
    Ctrl-b "        split pane horizontally (top/bottom)
    Ctrl-b arrow    move between panes
    Ctrl-b z        zoom/unzoom current pane (fullscreen toggle)
    Ctrl-b d        detach


3. TYPICAL WORKFLOW
--------------------

1. SSH into a remote server.
2. Start a named session: screen -S work   OR   tmux new -s work
3. Run your long-running command (e.g. a build, a monitoring script,
   an install).
4. Detach: Ctrl-a d (screen) or Ctrl-b d (tmux).
5. Disconnect / close the terminal / go home.
6. Later, SSH back in and reattach: screen -r work  OR  tmux attach -t work
   Your command is still running, output is all there.


4. WHICH ONE TO USE?
---------------------

- screen: simpler, pre-installed on almost every Linux/Unix system,
  good enough for "just keep this running" use cases.
- tmux: more modern, more configurable, nicer scripting/session
  management, better default pane-splitting. Generally the preferred
  choice today if you can install it.

Both do the same core job: keep processes alive across disconnects and
let you get back to them later.
